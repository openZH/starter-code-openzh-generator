# Generator notes

- The Requests notebook loader must decode HTTP compression and wrap `response.raw` in `BufferedReader` for pandas' Python CSV engine. Passing the raw response directly caused the delimiter sniffer to receive bytes instead of text. Set `raw.auto_close = False` so buffered reads can finish at EOF; nested context managers close the buffer and response. Loopback tests cover plain/gzip responses, headers, timeouts, streaming, HTTP/parsing errors, and cleanup.

- Metadata lists (keywords, themes, publishers) should render as comma-separated values, not Python list representations. The old two-pass escaping encoded apostrophes with `html.escape`, then escaped the `#` inside its own `&#x27;` entity; notebook renderers displayed the entity literally. Escape original characters in one pass and preserve literal source entities without decoding them.
- Dataset and resource `issued`/`modified` timestamps replace the ISO date/time separator `T` with a space for display only. Preserve timezone suffixes, fractional seconds, date-only values, and source metadata; do not apply this replacement to titles or other free text.

- Ruff formatting treats notebook placeholders as Python set expressions and removes their inner spaces. This caused CI run `36334659162` to fail: literal marker counting missed `{{DISTRIBUTION}}`, while substitution left `{{USER_AGENT_LITERAL}}` unresolved. Marker substitution and Python/R loading-marker counts now share a whitespace-tolerant pattern. Template execution tests use the same renderer; keep the compact/spaced, unknown-marker, and missing/duplicate-marker regressions.

- Typer forces terminal styling when `GITHUB_ACTIONS` is set. ANSI style sequences can split option names in captured help output, making raw substring assertions fail even when the CLI succeeds. The installed-entry-point smoke test strips ANSI styling before checking option names and covers both plain and colored output outside the checkout.

- CSV rows consistently wider than their header can make pandas infer an index and silently shift values under the wrong column names, even with the correct explicit separator. The Python helper rejects inferred indexes unless `index_col` is explicitly selected; intentional indexes remain supported. Regression cases cover trailing empty fields and extra values. Do not replace this guard with `index_col=False` alone, which can discard extra fields instead.

- A trailing CSV separator creates a blank header and an all-missing field. Reproduced pandas' `Unnamed: 11` with eleven named fields followed by a trailing comma; the source CSV in the user's screenshot was not available. Both template loaders now remove fully missing columns matching the parser's generated-name pattern, log their names, and preserve named missing columns, populated unnamed columns, and header-only schemas. This is a naming heuristic: use `drop_empty_unnamed=False` (Python) or `FALSE` (R) to retain intentional names matching the pattern. R execution still requires validation in an R environment.

- Duplicate cells in Colab originated in `_templates/template_python.ipynb`, which contained two complete notebook sections. The previous generator filled every distribution placeholder and preserved the template's cell sequence; the resource generator now requires exactly one loading marker. Keep one complete section in the template; do not deduplicate generated cells indiscriminately, since blank cells and user-authored repetitions can be intentional. The regression test generates notebooks with one and two CSV distributions and checks section order and single occurrences of data-loading code.

- Resource notebooks use `<dataset-id>--<ktzhDistId>` filenames; `manifest.json` is the authoritative ID-to-file mapping. Dataset-level selection notebooks were removed because they created an apparent duplicate for every single-resource dataset. Only resource notebooks are emitted; README and index provide selection links, and regeneration removes legacy dataset paths. Missing resource IDs use `url-` plus 12 SHA-256 hexadecimal characters of the download URL, so their filenames change when URLs change. Regeneration removes the previous pair-hashed filenames. Case-insensitive filename checks reject delimiter ambiguity, duplicate IDs and fallback collisions before replacing output.
- Generation is CSV-only: the catalogue `format` is trimmed and normalized for case before filtering, independent of URL suffixes or old `filters` settings. Parquet loading and R online launchers have been removed; obsolete configuration keys are ignored and cannot re-enable them. The nested-Parquet EDA follow-up is no longer applicable.
- Publication stages and verifies all expected files before replacing the output root. The notebook directories are fully managed; other output files are preserved. Two-rename replacement rolls back ordinary errors but is not crash-atomic: a leftover sibling `.OUTPUT.previous` is retained for manual recovery and blocks further generation.

- Release-preservation tests must compare all file bytes, not only `manifest.json`: a rollback can retain the manifest while damaging published artifacts. Verification tests separately exercise checksums and Python syntax with a matching checksum, since either gate alone can hide a regression in the other. Recovery tests retain a failed-rollback backup and verify that a subsequent run refuses to overwrite it.
