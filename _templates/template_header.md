# Starter code for CSV resources from the Canton of Zurich

💡 Ever **wished you could open a dataset in a data portal with one click and get a ready-to-use Python Jupyter Notebook or R Markdown file, complete with metadata, descriptions, data links, and starter code?**

This repository provides starter code for **resources listed as CSV** in the [data shop of the Office for Statistics and Data of the Canton of Zurich](https://www.zh.ch/de/politik-staat/opendata.zhweb-noredirect.zhweb-cache.html?keywords=ogd#/).

Browse **{{ DATASET_COUNT }} datasets and {{ RESOURCE_COUNT }} resources**. Each notebook loads one CSV resource and includes metadata, summaries and plots.

Open Jupyter notebooks in **Google Colab** to run Python in your browser, or use a local notebook environment. R Markdown files require a local R environment with tidyverse and skimr. Notebook and R Markdown links open the source files; packages are not installed by the notebooks.

⚠️ To download a file from GitHub, open its `RAW` view and select `Right-Click Save As`; otherwise, GitHub may save an HTML page instead of the file.
